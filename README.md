# Crimson Custom Cakes – Digital Photo Booth

A free, mobile-first browser photo booth. Customer photos are processed locally in the browser and are not uploaded.

## Publish with GitHub Pages
1. In your repository, choose **Add file → Upload files**.
2. Upload `index.html` from this folder and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then Save.
6. Wait for the published URL shown on the Pages settings screen.
7. Open that URL on a phone and allow camera access.

Camera access requires HTTPS; GitHub Pages serves the site over HTTPS.

## Notes
- This starter uses a text-based brand treatment. Replace the flower mark and text with the supplied business logo when ready.
- Native file sharing depends on the phone/browser. If unavailable, customers can download the image and share it manually.
- Test on a real iPhone and Android phone before printing the QR code.
- No photos are sent to a server by this page.
